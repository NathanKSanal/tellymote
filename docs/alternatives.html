TellyMote vs other ways to control an Android TV from your PC

TellyMote is a desktop app that sends remote keys to an Android TV or Google TV over your local network, and can show the TV's live screen on your PC. It is LAN-only: no account, no cloud relay, no telemetry. The same app also sends remote keys to Roku. This page compares it with the alternatives, including the cases where one of them is the better choice.

Straight answer

When TellyMote is the wrong tool

If all you want is low-latency mirroring of one Android device on a PC, and ADB is already set up, use scrcpy. It does that job better: it is built for mirroring, it is mature, and it carries no extra surface. TellyMote's screen view exists so the remote and the picture sit in the same window, not to beat a dedicated mirroring tool.

A few other cases where something else fits better:

  • You only have a phone and no PC. The Google TV app is the straightforward route; it needs a Google account, which TellyMote deliberately avoids.
  • You want a general-purpose PC remote for many devices, not just a TV. Unified Remote covers more ground, at the cost of a server component and an account model you should read up on.
  • You are automating a device for testing. Plain adb shell input scripts are more scriptable than any GUI, and easier to put in CI.
  • You want Roku screen capture. TellyMote does not do it, and neither does anything on this page. Roku's ECP is a control interface.

FAQ

Common questions

Does TellyMote need developer mode?
Only for part of it. Remote keys work over the Android TV Remote v2 protocol without developer options. Text entry, the app list and the live screen view use ADB on port 5555, which does need ADB debugging enabled on the TV.
Does TellyMote phone home?
No. There is no account, no cloud relay and no telemetry. The app talks to your TV across your local network, and release checks are ordinary GitHub downloads you start yourself.
Does it work with Roku?
Partly. Roku support uses ECP on port 8060 and covers remote keys, app launching and text entry. There is no screen capture for Roku, because ECP does not provide one.
What does the licence allow?
TellyMote is FSL-1.1-MIT: source-available, free for non-competing use, and each release converts to the MIT licence two years after it ships.
