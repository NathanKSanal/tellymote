Before you install

Good to know

  • Windows: unsigned, so SmartScreen may ask you to confirm. Use the portable-safe ZIP if Smart App Control blocks the installer.
  • macOS: unsigned ZIP; right-click → Open the first time.
  • Linux: AppImage; chmod +x then run.
  • Roku: remote, apps and text only — no live video.
  • DRM: Netflix/Prime/Disney+ show black in the live view.
  • Live view on Android TV needs ADB debugging enabled.
