# Promo video

A 47-second narrated promo for TellyMote, built with [Remotion](https://github.com/remotion-dev/remotion).
Everything is generated from this folder — no stock footage, no licensed music, no external services
except the free Microsoft neural voice used for the narration.

## Output

| File | What it is |
| --- | --- |
| `out/tellymote-promo-final.mp4` | Final cut: video + narration + ambient bed, −16 LUFS |
| `out/tellymote-promo-vo.mp4` | Picture with narration only, before the music mix |
| `public/tellymote-promo.srt` | Captions, one cue per narration line |

## Pipeline

```bash
npm install            # once; pulls Remotion + React
npm run vo             # 1. narration -> public/vo/vo*.mp3   (needs `py` + pip install edge-tts)
npm run timing         # 2. measures the VO and writes src/timing.ts + the .srt
npm run music          # 3. synthesises the ambient bed -> public/music/bed.wav
npm run render         # 4. renders picture + narration -> out/tellymote-promo-vo.mp4
npm run mix            # 5. ducks music under the voice, normalises -> out/tellymote-promo-final.mp4
```

`npm run build` runs steps 2–5. It does not re-record the voice; that is deliberate, because
re-recording changes every scene length and usually needs a listen first.

`npm run studio` opens the Remotion preview so you can scrub the timeline while editing.

## How the timing works

`scripts/make_vo.py` writes one MP3 per scene and prints its measured duration.
`scripts/make_timing.mjs` converts those durations into frame counts (30 fps, 0.45 s lead-in,
0.55 s tail per scene) and writes `src/timing.ts`. The composition reads its scene starts and its
total length from that file, so the picture can never drift away from the voice.

If you change a line in `scripts/narration.json`, run `npm run vo && npm run timing` and the whole
cut re-times itself.

## Audio levels

- Voice: Microsoft `en-US-AndrewNeural`, +3% rate, −2 Hz pitch.
- Music: four-chord A-minor pad, generated by `scripts/make_music.mjs` (no sampling, no licence).
- Mix: music at 0.55 gain, side-chain ducked under the voice, then `loudnorm I=-16 TP=-1.5`.
  That is the level YouTube and most players expect; quieter uploads get normalised down anyway.

## Voice choice

`en-US-AndrewNeural` is described by Microsoft as *warm, confident, authentic, honest*, which matches
the product's tone: no hype, no "revolutionary". If you re-record, keep the same register — the
script is written for a measured delivery, not an advert shout.
